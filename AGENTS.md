# Working in this repository

For a film request, read `skills/motion-reel/SKILL.md`, initialize a project under `work/<name>/`, and produce the user's film there. `work/` is ignored. Do not edit the toolkit for an ordinary film request.

For toolkit maintenance, keep its instructions self-contained and agent-neutral. Preserve scoped user authorization; do not add unconditional approval gates or automatic publication. Run `python3 tests/check_bundle.py` and a real browser still/render for changed production code. A static test does not establish visual quality or platform support.

Do not put credentials, personal paths, private conversations or unlicensed font files in this repository. Keep media outputs in Releases rather than Git. Preserve third-party notices. Use the native skill creator available in the host when editing the skill.
