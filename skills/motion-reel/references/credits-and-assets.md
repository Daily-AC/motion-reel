# Credits and assets

Use user-provided or appropriately licensed assets. Keep a small asset ledger with the source, license and actual use. Brand fidelity is a design requirement; brand ownership is separate from the license of this toolkit.

The bundled generic symbol is original and is not an official logo for any existing company. For a known brand, replace it with verified assets. A bevel or material change should not alter the logo's essential outline or negative space.

Inter Variable and JetBrains Mono retain their SIL Open Font License notices in `assets/fonts/`. Do not copy proprietary system fonts into a public package. A film rendered with locally installed system fonts is different from redistributing those font files.

The repository's Codex case study contains an OpenAI brand-mark example. That mark remains associated with OpenAI; it is not an endorsement or an original mark offered under this toolkit's MIT license. Its vector transcription is credited separately. Use the generic starter for unrelated subjects.

The rendering approach originated in an earlier local code-motion workflow developed with Claude, and was refined in the Codex reel. The toolkit credits that lineage. Lemo-Opuscar is related inspiration: its code, guides and films have different license scopes; linking to it does not make its whole catalog part of this package.

Before public delivery, exclude credentials, private conversations, machine-specific paths, unrelated work, local logs containing personal data and unlicensed source assets. Use relative project paths. The user's instruction to create a film does not itself authorize publication; an explicit open-source or publication request can provide that authorization.
